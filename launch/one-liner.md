# The Official zer0Gig One-Liner

> One sentence that works everywhere. If you can't explain what you're building in one sentence, judges won't get it either.

This page is the **single source of truth** for how to describe zer0Gig in copy. Use it verbatim on the landing hero, X bio, pinned tweet, pitch-deck cover, investor email, GitHub README, and Discord intros.

---

## THE One-Liner (canonical)

> **zer0Gig is a decentralized marketplace where AI agents are minted as Intelligent NFTs and hired via smart-contract escrow that releases payment only when work passes cryptographic quality attestation — the first production deployment of ERC-7857 + ERC-8183 on 0G.**

That's the sentence. Memorize it. Don't paraphrase.

### Why this sentence works

The formula:

```
audience    +  core value                                       +  differentiation
─────────────  ──────────────────────────────────────────────  ───────────────────────
"AI agents"    "minted as iNFTs and hired via escrow that         "first prod deployment
               releases payment only when work passes              of ERC-7857 + ERC-8183
               cryptographic quality attestation"                  on 0G"
```

- **Audience:** AI agents (and by extension, their owners and clients) — concrete, not "users" or "developers"
- **Core value:** payment is gated by cryptographic verification, not trust — solves the central problem of AI commerce
- **Differentiation:** first production deployment of two emerging EIPs — specific, falsifiable, defensible

## Three Concepts You MUST Keep

Whenever someone (team member, copywriter, AI assistant) rewrites zer0Gig copy, the result must include these three concepts in some form. Drop any of them and the differentiation collapses.

| Concept | Canonical phrasing | Why it matters |
|---|---|---|
| **iNFT identity** | "minted as Intelligent NFTs" / "ERC-7857" | Separates us from generic AI marketplaces |
| **Cryptographic payment gate** | "alignment attestation" / "ECDSA-signed quality score" | The whole economic model rests on this |
| **First production deployment** | "first prod deployment of ERC-7857 + ERC-8183" | The standards-grade claim — defensible only because we shipped first |

---

## Anti-Patterns (Don't Say This)

| Don't say | Why it's wrong | Say instead |
|---|---|---|
| "AI-powered marketplace" | Generic — every Web3 project says this | "Marketplace where AI agents are minted as Intelligent NFTs" |
| "Next-generation gig economy" | Empty hype, no specifics | "The first ERC-7857 + ERC-8183 production deployment" |
| "Revolutionary platform" | Cliché, makes investors mute | Drop the adjective; let the architecture speak |
| "Blockchain-based freelance" | Vague — could be anything | "On-chain escrow with cryptographic quality attestation" |
| "Connecting clients and AI" | Doesn't describe what's new | "Hiring AI via smart contracts that pay only on verified work" |
| "Decentralized AI infrastructure" | 0G already owns this position | "The agentic commerce layer on 0G" |
| "Trustless AI economy" | Buzzword soup | "Payment released only when alignment attestation passes" |

## Approval Flow for Copy Changes

If you (or any AI agent generating copy) want to change the canonical one-liner:

1. **Run the change through the three must-keep concepts test.** If any concept is dropped, reject.
2. **Compare character/word count vs the original.** Shorter is fine; longer needs justification.
3. **Read it aloud.** Does it parse on first hearing? If you stumble, judges will too.
4. **Ping Hans before publishing** any variant that materially diverges.
